# P5 体验提升第一批开发记录

2026-10-14，Asia/Shanghai，P5-09。已交付开发候选，待用户手工体验；第二批依批准计划在反馈后推进，正式统一验收未执行，P6未启动。

## 需求与实现

用户先要求分析游戏效果、制定提升计划，随后要求审查、按审查意见修订，并批准按计划实施。第一批采用音画反馈、即时完整楼体、展示队列与镜头控制、楼名避让/聚合展开和多结果搜索。[已批准计划](P5-experience-enhancement-plan.md)保留两批边界。

- 普通落层增加轻量光效和短促合成音；Perfect光圈及音色区分，连击音高五级封顶，仅反馈。13层、25层提示外观升级。点击内初始化音频，音频拒绝不阻塞服务端开局或提前计时；静音可记住，暂停/后台停止声音。没有背景音乐或震屏。
- 删除城市楼体纵向缩放，快照到达即原地显示完整最新楼体，避免压缩窗格和照片。特写仅控制镜头、高亮与提示，不延迟成绩/模型显示、不拼接两局或隐藏新楼重播。
- 待展示队列最多20项，同人合并不延长原等待时间，纪录优先，超过20秒或过时run/epoch跳过；刷新、恢复、事件缺口与日切不补播旧队列。当前楼再创新高更新模型和提示，不重启过场；集中提交不保证每栋都有特写。
- 镜头统一手动/暂停优先于事件、事件优先于巡游。拖动、缩放、选楼、搜索/街区接管；空闲20秒恢复，显式暂停须主动恢复。选中楼更新不自动取景。巡游穿插全景、街区和楼体，慢弧线可调；照片正面取景，预设抬高/平移/靠近路径检查建筑包围盒，拥挤退为高位视角。减少动态偏好关闭弧线并静态切换，不声称通用碰撞寻路完成。
- 楼名按优先级避让浮层，偏移加引导线；拥挤名称以数量标记展开全部成员。搜索返回多个匹配，楼名/地块区分，按玩家ID定位，前十名外也能查找；复用大屏快照，不增加手机全城读取。碰撞约10Hz、文字尺寸缓存，保留偏移减少跳动。
- B/60秒、原计分/裁切、连击仅反馈、随机地块、六色、照片及午夜清空规则保持；本次无服务端/schema/上传协议变更，不调用清空或更改云任务。

## 实际检查与失败记录

- 新增队列、镜头优先级、路径相交及密集标签定向检查；既有核心模型、共享客户端和外观检查一并执行。先34/34，再加入实际镜头/渲染更新检查后36/36，均使用Node22.22.2的experimental-transform-types。实际命令为：node --experimental-transform-types --test tests/presentation.test.ts tests/camera-presentation.test.ts tests/core.test.ts tests/shared-client.test.ts tests/appearance.test.ts。这是开发契约/逻辑检查，不是WebGL满城性能、真实手机或线上D1验收。
- 镜头检查使用实际CityCamera与最小事件目标替身；渲染更新检查调用实际setCity但不启动WebGL，证实新最佳完整高度、scale1，不将它冒称浏览器照片实测。
- 第一次主流程编辑脚本因持久REPL已有常量名冲突而在写文件前失败；首次类型检查因此发现尚未替换的旧长高函数调用。重新使用有作用域的脚本后修正。查找两个不存在的旧测试文件时也返回缺失，随后按实际测试清单执行，没有虚构其结果。
- build-1停在新增测试夹具类型错误：事件遗漏revision/plotId，matchMedia替身断言不完整；修正后build-2及最终CSS修订后的build-3成功。保留全部失败与bundle大小等警告。测试先于提交，候选工作区与最终38c459f关联；随后测试夹具只补类型，列表修复只改CSS，36项逻辑检查未再次执行。
- Wrangler本地HTTP200；1920×1080浏览器模拟页面12栋样例，实际展开3栋聚合名称、多匹配搜索2项。初次点选列表未定位，确认继承父层pointer-events:none；显式开放点击后复测，能定位排行前十之外的7层地块12，状态显示正确分区/楼名。原失败和修复均保留。
- 390×844本地尺寸模拟能开始60秒、切静音及暂停（观察时剩52秒）；未跑完整一局或提交。另一1920×1080只读test城观察为空城0栋，全屏、二维码、榜单和巡游入口可见。没有向线上真实城写模拟成绩。
- 发布后浏览器实际读取共享首页：音效开关、开始盖楼、我的楼、真实共享说明可见；保存DOM和截图。没有执行线上开局/提交、上传或免登录独立浏览器验收，不从首页访问推断全链路通过。
- public推送前审查实际14文件、待推commit、全历史对象/tag和既有5张PNG哈希/元数据；首次审查因计划末尾多余空行停止，规范化后通过。提交前扫描574个对象，应用推送前596个对象，敏感命中0；源码和tag正常推送，无强推。
