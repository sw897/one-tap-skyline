# P1 实施边界

游戏：《一指盖楼：城市天际线》。维持 V0.3 产品/阶段基线，采用 V0.3.1 公开安全及私有留证规则。技术路线已获准：TypeScript、Vite、Three.js 静态前端。

## 运行时活动配置

- 浏览器启动时读取同源 `/runtime-config.json`，不将活动值编译进 JS。仓库内默认文件只使用“城市天际线”；不存在、异常或不合法的值回退到安全默认。
- 本地开发可通过 `SKYLINE_ACTIVITY_CONFIG_PATH` 指向仓库外 JSON，由开发服务器响应上述路径；原文件不复制进源码或构建目录。静态部署可在服务层替换同路径响应，具体托管能力须实测。
- 只接收白名单字段：城市显示名、玩法和镜头参数；文字使用文本节点呈现。运行时展示配置可被访客读取，不能承载秘密、身份凭据或私有个人数据。
- 公开源码、默认构建与 Sites 候选版本保持中性名称。内部活动覆盖只用于已授权的受控环境；不将本地覆盖文件打包或提交。

## 统一游戏规则

- 楼块只沿 X 轴往返，深度固定。以相邻楼层 X 区间交集裁切；交集大于数值误差即保留，零交叠结束。
- 每个成功落层计 1 层，基座计 0；高度等于基座高度加层数乘统一层高。Perfect 在配置容差内吸附至前一层中心；连击只产生反馈，P1 不加虚拟楼层、不修复宽度、不另算排名分。
- 一次有效输入固定当时位置并完成几何判定；落层动画期间拒绝追加输入。计时结束或失败后冻结这局。页面隐藏时暂停时钟和移动，返回后显式继续。
- 正数层数的结束局才能模拟入城；尚在进行、零层和重复提交不会改变城市。计时、速度、容差、连击阈值和动画时长都是初始候选配置，P2 才凭实际试玩调整。
- 玩法、结算与城市都消费同一 `TowerModel`；城市保存新最佳的完整几何。未破纪录不更换主楼，新最佳在原地替换最佳几何并动画揭示新增高度，不拼接不同局的楼层。
- P1 玩家和城市只存在于本页内存；同一页重复游玩复用地块、颜色、署名。页面刷新会重置模拟，不代表跨设备身份或云端保存。

## 真实手机验收安排

- 计划使用真实 iPhone Safari 与安卓 Chrome 各一次，记录机型、系统/浏览器版本、访问地址、commit/tag 和测试时间；手机尺寸模拟单独标注。
- 同一 Wi-Fi 优先访问局域网运行地址；连接或防火墙受限时记录原因，采用已核实受众的 Sites 地址。私有 Sites 可能要求账号，不能据此宣称匿名访问通过。
- 每机检查：首次无需游戏账号即可开局；单指与快速连续点击；计时/暂停；横竖屏旋转；完整楼体结算；首次入城、未破纪录不变、新最佳原位变高；清晰的模拟标签。
- 保留两机实录或实际反馈，并记录明显掉帧、误触和发热；没有操作真实设备的证据则标“待验证”，不能用模拟结果代替。

## Sites 预检基线与实施后状态

技术方案审核时的 P0 基线：**仅完成预检，实际部署与免登录访问待验证。** 当时只创建私有项目、核实 owner 和仅本人访问、打开本地 Git 源通道，尚未保存或部署。

2026-10-11 实施后：Sites 版本 1 已保存并部署成功；受众经明确确认改为任何知道链接的人。两个全新未登录 Chrome 会话返回 HTTP 200，实际触控开局、结算和模拟入城通过。首次访问中发生的 403 保留在私有失败记录中。真实 iPhone 的 Safari、Chrome 和微信内置浏览器免登录及触控获反馈通过；启动和切页闪动已作 P1 修订。2026-10-12 收到 iPhone 复测确认，闪动已修复；安卓及完整三情景真机验收仍待补。发布地址与构建一致性见 [验证摘要](P1-validation.md)。
