# 最终统一验收清单

先由用户手工体验、修复实际反馈，再冻结候选组织统一验收。这里保留有效要求，不把开发检查或旧版局部反馈写成全面验收通过。操作见[运行说明](deployment.md)，原阶段计划/审查稿已在仓库外归档。

## 产品基线

- 逐层X/Z交替、每层单轴、一指点击、60秒有效时间，连击仅反馈。手机只看自己的最佳楼，大屏只读城市；三端共用真实主体几何/层高，新最佳采用完整新局模型。
- 固定六区76展示位，全部有效最佳保存；同分先到竞争展示位，官方排行仍并列。已展示楼新高原地替换，退出展示保留作品，新高可重新竞争，不保证原地块。
- 外观1–12、13–24、25层以上，六色、官方前三顶饰；装饰不计分、不扩主体或遮照片。首次/严格新高可改名换图选色，低/同分不覆盖。
- 照片即时公开、自愿上传，可预览/换图/撤回；预览与真实墙形映射一致，不跨退台补墙。草稿4小时或午夜更早到期，成品午夜到期。退台内缩0.04、净宽至少0.16、长度至少0.24，饰件高度不超过层高0.24，空间不足省略。
- 大屏为明亮滨海城市、1920×1080 Chrome。屋顶楼名不聚合/避让/引导线，屋顶离开视口可隐藏，密集重叠单列观察。手动定位默认2.5秒可调，手动/暂停高于事件，事件高于巡游；队列有界并过期。
- 动态默认开启，摩天轮105秒一圈/支架固定/座舱竖直，9车移动；关闭、后台、减少动态偏好冻结。声音在用户点击内初始化，失败不阻塞开局或改变计时/成绩；普通/Perfect/连击/失误可辨，不据振动调用声明iPhone触感通过。
- 北京时间00:00清空玩家、局次、作品/成绩/排行/展示位、事件、照片/草稿和游戏限流记录，更新入口码。基础日标记、SQL版本、配置/证书、源码/Git及私有证据保留。

## 准备与检查项

冻结应用commit、构建标识、镜像/Worker版本、SQL版本、运行配置、实际Origin及入口，不新建阶段tag。逐项记通过/失败/未执行/受阻，关联证据和设备；修复后复测受影响项，不拼接旧版本结果。容量/故障数据只用于隔离test城和独立卷，不向真实城灌成绩/照片。真实手机、尺寸模拟、程序数据、HTTP、模型和画面分别表述。

## 当前缺项与判定

云端候选32项定向开发检查、构建、HTTPS/入口/缓存和局部Chrome渲染已有记录，不重复记为正式验收。目标冷构建下载受阻，当前导入校验镜像。真实云端手机完整流程、投屏、无人访问午夜、服务器重启/含照片更新/回退、容量性能和统一验收待执行。Sites保留旧部署，源码构建检查与实际发布版本分别记录。

安卓暂不测试。旧数据搬迁工具失败私存，生产不依赖它；不新增身份恢复、照片备份/审核角色或历史迁移系统。必要项失败先修复，缺证据标缺项，由用户决定补测或接受；Sites是否停用/收窄受众及旧任务处理另行决定。
