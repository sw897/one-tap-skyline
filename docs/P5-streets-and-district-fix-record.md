# P5 满城路网与街区定位修复记录

2026-10-14，Asia/Shanghai。P5-15；Sites21已发布，尚待用户手工复测。

## 反馈、原因及完成项

用户在满城模拟中发现桥畔街区68/69地块盖住道路、缺少环岛公路、街区道路断头、运河未接湖泊、桥不接路、楼名太大和街区选择不定位。

修复前基于真实源码的复现：旧大道平滑路径进入68/69地块范围，中心线到地块边界的最小间距为0；旧路线节点落入该区域，绕行失败仍可返回原路线。道路按节点做绕行后再用样条平滑也可能削掉间距。满城六区逐一选择时，镜头遮挡保护把目标改成了“海岛全景”；下拉控件本身有响应。

本轮完成：

- 闭合环岛公路，各街区中央街道两端接环岛路；连接点保持准确，不因寻路网格近似产生断口。路线绕开玩家地块、中央湖及公共建筑；不移动既有plotId或楼。
- 道路用安全折线与圆角绘制，移除对绕行道路的样条二次平滑；仍统一绘制到一张地面材质，不新增道路交汇处共面争深度。路旁树木避开道路。
- 运河起点在中央湖内，末端延伸到岸外；桥按路水实际交点和道路方向生成，桥面/栏杆及两端坡道接路。默认六区有4处过水桥。
- 大屏屋顶楼名18px改12px，内边距6×10改3×5；排行榜与标题字号保持。继续简单顶部投影，密集楼名仍可能重叠，不引入聚合、指示线或动态避让。
- 街区定位遇遮挡时提高所选街区的机位，保留该区目标，不退回全岛；2.5秒手动定位、暂停巡游时的选择及返回全景可用。B/60秒、成绩、照片、扫码资格和午夜任务未改。
